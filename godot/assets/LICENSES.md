# SWARM asset licenses (Build #15)

## Audio

All runtime audio in this project is **procedurally generated in Godot** by
`godot/audio/swarm_audio.gd` (WAV buffers synthesized at runtime).

- **License:** CC0 1.0 Universal (public domain dedication)
- **Source:** Original procedural synthesis for SWARM — no third-party sample packs,
  voice clips, or commercial libraries.
- **Contents:** Rod ambient loops (Mycelium wet/earthy hum, Apis meadow buzz, menu
  blend), UI click/hover cues, placement / pulse / soft event tones.

No external audio files are shipped under `godot/`.
